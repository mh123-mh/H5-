# 🌍 我是环境检察员 - 塔防游戏

一个以环保为主题的 HTML5 塔防游戏，适合在浏览器和移动设备上玩。

## 🎮 游戏介绍

在这个游戏中，你将扮演一名环境检察员，使用各种环保塔来抵御污染怪物的入侵！

### 游戏特色
- 🏰 **8种不同类型的塔**：基础塔、净水塔、光能塔、彩虹塔、风力塔、太阳能塔、净化塔、雷电塔
- 👹 **8种污染怪物**：从垃圾怪到Boss级的环境破坏王
- ⚔️ **5波次战斗**：难度逐渐增加
- 📱 **响应式设计**：完美支持移动设备
- 🌱 **环保主题**：寓教于乐

## 🚀 如何游玩

### 本地游玩
1. 克隆或下载此仓库
2. 使用浏览器打开 `index.html`
3. 或者使用 Node.js 服务器：
   ```bash
   node server.js
   ```
4. 在浏览器访问 `http://localhost:9000`

### GitHub Pages 部署
1. 将代码推送到 GitHub 仓库
2. 在仓库设置中启用 GitHub Pages
3. 游戏将可通过 `https://yourusername.github.io/repo-name/` 访问

## 🎯 游戏玩法

1. **选择关卡**：从首页开始，选择关卡
2. **选择防御塔**：在游戏准备界面选择你想要使用的塔
3. **放置塔**：在战斗场景中将塔放置在墙上
4. **升级塔**：点击已放置的塔可以升级或拆除
5. **战斗**：塔会自动攻击怪物，阻止它们到达右侧
6. **胜利条件**：成功防御所有波次，包括Boss波
7. **失败条件**：生命耗尽或Boss逃脱
